# オブジェクトの parse / Diff の動作検証サンプル

`before/` と `after/` に、sfdx の形式（`force-app/main/default/objects/<API 名>/`）でオブジェクトのメタデータを、`force-app/main/default/objectTranslations/<オブジェクト>-<言語>/` にオブジェクトの翻訳を置いている。本番と同じ流れ（`MetadataParser.parseObjects`、`ObjectTranslationParser.parseObjectTranslations`）で読む。翻訳は [object-translation.md](../../object-translation.md)。

```sh
# parse: before / after を JSON にする
npx ttsx --noCheck docs/examples/metadata/run-parse.ts
# Diff: before と after を比べる
npx ttsx --noCheck docs/examples/metadata/run-diff.ts
```

| 出力                                                                                         | 内容                                                                                   |
| -------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| parse-output/&lt;before\|after&gt;/objectTranslations/&lt;オブジェクト&gt;-&lt;言語&gt;.json | `ObjectTranslationFileStructureType`                                                   |
| parse-output/&lt;before\|after&gt;/&lt;API 名&gt;.json                                       | `ObjectFileStructureType`（`MetadataParser.saveObjectFileForDevelopper` と同じ形）     |
| [parse-output/summary.md](./parse-output/summary.md)                                         | オブジェクトごとの子の件数、読めなかったファイル、解析（項目の値の型・参照関係）       |
| diff-output/object-diff.json                                                                 | `makeObjectUnitDiffs` の結果                                                           |
| [diff-output/summary.md](./diff-output/summary.md)                                           | unchanged 以外の差分を、ファイルと行付きで木の形に並べたもの                           |
| [diff-output/coverage.md](./diff-output/coverage.md)                                         | kind ごとの、JSON と差分のノードへの出現数                                             |
| diff-output/translation-diff.json                                                            | `makeObjectTranslationUnitDiffs` の結果（オブジェクトの翻訳）                          |
| [diff-output/translation-coverage.md](./diff-output/translation-coverage.md)                 | 翻訳の網羅（未翻訳・翻訳元と同じ・宙に浮いた翻訳・古い翻訳）                           |
| diff-output/report-data.json                                                                 | viewer に渡す表示用データ（MCP の `analyze_objects` で `isDiff: true` のときと同じ形） |

期待どおりかどうかは、テスト [test/parser/metadata-parse.test.ts](../../../test/parser/metadata-parse.test.ts)、[test/processor/metadata-diff.test.ts](../../../test/processor/metadata-diff.test.ts)、翻訳は [test/parser/object-translation.test.ts](../../../test/parser/object-translation.test.ts) と [test/processor/object-translation.test.ts](../../../test/processor/object-translation.test.ts) で確かめる。サンプルは、すべての kind が差分のノードとして 1 回以上現れるように書いている。
