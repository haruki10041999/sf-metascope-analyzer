# オブジェクト（メタデータ）のサンプル

実装の全体は [metadata-implementation.md](../../metadata-implementation.md)、翻訳は [object-translation.md](../../object-translation.md)。`samples/before` と `samples/after` に、sfdx の形式（`force-app/main/default/objects/<API 名>/`、`objectTranslations/<オブジェクト>-<言語>/`）で置いている。

| フォルダ                                 | 内容                                                                                                                                                                                                                                                                                   |
| ---------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [samples/](./samples/)                   | `before/` と `after/`（下の表）                                                                                                                                                                                                                                                        |
| [scripts/](./scripts/)                   | `run-parse.ts`（JSON と要約）、`run-diff.ts`（before → after の Diff）、`run-folders.ts`（権限・ラベル・Flow・画面の JSON・Diff・解析）                                                                                                                                                |
| [output/json/](./output/json/summary.md) | オブジェクト・翻訳の JSON、`summary.md`（子の件数・読めなかったファイル・解析の結果）。権限などは `<side>/<フォルダ>/` と [folders.md](./output/json/folders.md)                                                                                                                       |
| [output/diff/](./output/diff/summary.md) | `summary.md`・`coverage.md`・`object-diff.json`、翻訳の `translation-diff.json`・`translation-coverage.md`、viewer 用の `report-data.json`。権限などは `folder-diff.json` と [folders.md](./output/diff/folders.md)。レポートの data provider の出力は `output/report/<provider>.json` |

```sh
npx ttsx --noCheck docs/examples/metadata/scripts/run-parse.ts
npx ttsx --noCheck docs/examples/metadata/scripts/run-diff.ts
npx ttsx --noCheck docs/examples/metadata/scripts/run-folders.ts
```

権限・カスタム表示ラベル・Flow・ページレイアウト・Lightning ページ（[metadata-a-plan.md](../../metadata-a-plan.md)）のサンプルは、末尾の「フォルダ単位のメタデータのサンプル」。テストは [test/processor/metadata-folders.test.ts](../../../test/processor/metadata-folders.test.ts)。

期待どおりかどうかは、テスト [test/parser/metadata-parse.test.ts](../../../test/parser/metadata-parse.test.ts)、[test/processor/metadata-diff.test.ts](../../../test/processor/metadata-diff.test.ts)、翻訳は [test/parser/object-translation.test.ts](../../../test/parser/object-translation.test.ts) と [test/processor/object-translation.test.ts](../../../test/processor/object-translation.test.ts) で確かめる。サンプルは、すべての kind が差分のノードとして 1 回以上現れるように書いている。
