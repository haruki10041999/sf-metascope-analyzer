# LWC のサンプル

実装の全体は [lwc-implementation.md](../../lwc-implementation.md)。1 バンドル（フォルダ）を 1 つの単位として、JS / TS・HTML・CSS・js-meta.xml をまとめて読む。

| フォルダ                                                        | 内容                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| --------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [../repository/](../README.md) の `force-app/main/default/lwc/` | before: 構文をひととおり含むバンドル（`accountList`: `@api` / `@wire`（import の項目・文字列の `fields`）/ getter / `NavigationMixin` / 関数のフィールド / `then`・`catch` / `updateRecord`・`refreshApex` / `querySelector('c-account-row')` / `addEventListener` / `lwc:if` / `for:each` / `iterator` / 子コンポーネント / `:host` / カスタムプロパティ、`accountRow`: 子、`utils`: 共有モジュール（コンポーネント以外のクラス `RowCache`・`for of` / `if` / `switch` の本体・`export { formatAmount as format }`）、`broken`: LWC の仕様違反、`oldBanner`）。変換のテストは before を使う。after: Diff 用の変更（期待する差分は [lwc-implementation.md](../../lwc-implementation.md)） |
| [scripts/](./scripts/)                                          | `generate-json.ts`（全サンプルの JSON）、`run-diff.ts`（before → after の Diff）、`run-library-parse.ts`（ライブラリが返す木の属性の一覧。生成物 `output/library/` は持たない）、`verify-erase-types.ts`（TS の型を空白にする処理の検証）、`ssr-snapshot/`・`ssr-lbc/`（画面モックの試作。[lwc-snapshot-plan.md](../../lwc-snapshot-plan.md)）                                                                                                                                                                                                                                                                                                                                            |
| [output/json/](./output/json/index.md)                          | バンドルごとの JSON（`LwcBundleParseResult`）                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| [output/diff/](./output/diff/summary.md)                        | `summary.md`（unchanged 以外の差分）、`bundle-diff.json`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |

```sh
npx ttsx --noCheck docs/examples/lwc/scripts/generate-json.ts
npx ttsx --noCheck docs/examples/lwc/scripts/run-diff.ts
npx ttsx --noCheck docs/examples/lwc/scripts/run-library-parse.ts   # --raw でライブラリの木をそのまま出す (コミットしない)
npx ttsx --noCheck docs/examples/lwc/scripts/verify-erase-types.ts  # --print で空白にした JS を表示
```

期待どおりかどうかは、テスト [test/processor/lwc-diff.test.ts](../../../test/processor/lwc-diff.test.ts) と `test/converter/lwc-*.test.ts`・`test/parser/lwc-*.test.ts` で確かめる。
