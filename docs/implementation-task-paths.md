# 実装タスク別の変更先と実装方針

[実装タスク一覧](./implementation-tasks.md) の108項目を元の順序で掲載しています。パスはリポジトリルートからの相対パスです。各行の番号は元の文書の行番号です。

「既存の変更先」は主な修正箇所です。「新規パス」は追加ファイルや生成先の候補で、末尾が / のパスはディレクトリです。「既存コードの改修案」は現在の関数や処理の変更点、「新規実装案」は追加する型・関数・部品の案です。新規パスが — の場合は、既存ファイル内への追加を想定しています。

provider の追加では `src/analyzer/report/registry.ts` と `src/analyzer/report/schemas.ts`、viewer 部品の追加では `src/report/catalog.ts` と `src/viewer/report/registry.tsx` が主な登録先です。項目によって、関連する既存テストや生成物も更新します。
