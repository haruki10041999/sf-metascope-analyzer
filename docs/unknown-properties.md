## 集計条件

- Git 管理対象および無視されていない未追跡の `.ts`・`.tsx` ファイルを対象とする。依存ライブラリ、ビルド出力、`.d.ts`、Git の無視対象は含めない。
- 構文解析で型属性、インデックスシグネチャ、mapped type、クラス属性、コンストラクタのパラメータプロパティを調べた。名前付き型だけでなく、型注釈・型ガード・型アサーション中の無名のオブジェクト型も含める。
- 属性の型に `unknown` が直接書かれたものに加え、配列・union・タプル・ジェネリック型の引数などに `unknown` が含まれるものも掲載する。例えば `data: Record<string, unknown>` は対象。
- `type Json = Record<string, unknown>` のような辞書型の別名も、値が `unknown` の属性を表すため掲載する。インデックスシグネチャと同じく、特定の属性名を列挙したものではない。
- 入れ子のオブジェクト型は、内側の対象属性を列挙し、外側の属性を重複して数えない。関数型の引数や戻り値だけに現れる `unknown` は、その関数型の属性自体が `unknown` ではないため対象外。
- 型エイリアスの解決・型推論は対象外。辞書型の別名以外の、属性宣言に属さない `Record<string, unknown>` の使用箇所も含めない。
- 各行は出現箇所ごとに数え、型属性の行番号を示す。所属は周囲の型・クラス・関数・変数などの名前であり、`(無名)` は名前の取れない箇所を示す。`?` は省略可能な属性。
